Neon Breach is a neon/cyberpunk tactical FPS built with three.js. First-person pointer-lock shooting, round-based 5v5 bot combat (you + 4 teammates vs 5 enemies), an economy with 5 buyable weapons, a HUD with health/ammo/round timer/score, a kill feed, and a full match flow from title screen to victory screen and restart.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests — the game is static files under `game/`.
